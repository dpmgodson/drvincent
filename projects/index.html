Current work

One project in build, one under consideration.

Concrete 3D printing can place material accurately. It still cannot place reinforcement. Until it can, printed construction remains limited to elements that do not need to carry much.

The funded project below addresses exactly that gap, and is the prototype behind the TriFusion filing.

Ongoing

Development of Multi-arm 3D Printing System with Integrated Horizontal and Vertical Reinforcement

Concrete 3D printing can place material accurately, but reinforcement still largely has to be added by hand, which removes much of the advantage automation offers. This project develops a multi-arm printing system in which horizontal and vertical reinforcement is integrated during deposition rather than afterwards.

Deliverables

  • TriFusion 3D printing prototype
  • Multi-arm reinforcement integration
  • A 2 ft × 2 ft working model
  • Structural validation
